# Herald PCB Reader（原 Altium Reader 2）

完全重寫的第二版（2.4.0 起改名為 Herald PCB Reader）：C# / .NET 10 WPF 原生 Windows 程式（2.8.0 起；之前是 .NET 8），介面仿 Altium Designer 19（深灰主題、可停靠面板、文件分頁）。
第一版（`../AltiumReader`，Electron）保留不動；安裝第二版後，`.SchDoc` / `.PcbDoc` / `.PrjPcb` 的預設開啟程式改為第二版。

**授權**：2.8.3 起依 **GNU GPL 第 3 版（GPL-3.0-only）**發佈，另依 GPL 第 7 條允許與 AvalonDock（Ms-PL）結合散布；全文見 `LICENSE.txt`，聲明與額外許可見 `NOTICE.txt`，詳見下面〈資安與授權〉。

## 執行檔

| 檔案 | 說明 |
|---|---|
| `dist\Herald PCB Reader Setup 2.9.4.exe` | 安裝版（只裝給目前使用者，不需系統管理員權限；已安裝過時可直接選「修復／更新」，不必先解除安裝） |
| `publish\HeraldPcbReader.exe` | 免安裝單一執行檔（已內含 .NET 10，不必另外安裝） |

安裝後位置：`%LOCALAPPDATA%\Programs\Herald PCB Reader\HeraldPcbReader.exe`

從 Altium Reader 2（2.0–2.3）升級：直接執行新的安裝檔即可。舊版的程式檔、捷徑與「已安裝的應用程式」項目會移除；設定（`%APPDATA%\AltiumReader2`）、最近開啟的檔案、群組與檔案關聯都保留。內部的檔案類型代碼仍是 `AltiumReader2.SchDoc` 等，所以先前勾過「一律使用此應用程式」的選擇會直接改開新程式。

### 檔案關聯

安裝程式會把 `.SchDoc` / `.PcbDoc` / `.PrjPcb` 的預設開啟程式設為 Herald PCB Reader（`.kicad_sch` 只加進「開啟方式」清單），並登錄到「設定 → 應用程式 → 預設應用程式 → Herald PCB Reader」。
原本的預設（例如第一版 Altium Reader）會記下來，解除安裝時自動還原。
程式圖示是晨星（2.5.2 起）：Herald 是帶來光明與晨曦的信使——夜空由深藍漸轉為黎明的金橘色，金色的四芒晨星高掛在弧形的地平線上，地面上幾條金色走線與焊墊延伸向曙光。檔案總管裡的圖示依類型區分：電路圖黃色「SCH」、PCB 綠色「PCB」、專案藍色「PRJ」（與文件分頁同色，大圖示左下角帶程式的晨星圖示；圖示檔在安裝資料夾的 `icons\`，由 `AdCli icon` / `AdCli docicons` 產生）。

Windows 的保護機制：如果某種檔案以前已經用別的程式開過（例如第一版、Altium Designer），第一次雙擊時 Windows 會跳出「您要如何開啟這個檔案？」——選 **Herald PCB Reader** 並勾「一律使用此應用程式」，之後就固定了。也可以直接到上面那個設定頁面一次改好。這個確認只有使用者能做，程式不能代替點選。在選定之前，檔案總管會把這種檔案顯示成空白圖示。

程式發生錯誤時會記錄在 `%APPDATA%\AltiumReader2\crash.log`，回報問題時可以附上。

全部功能離線可用（第一版的 3D 與 PDF 需要連網載入函式庫，第二版不需要）。

**使用說明**（2.6.0 起）：說明 → 使用說明，或按 **F1**，在預設瀏覽器開啟 HTML 說明（含介面截圖、各功能與快捷鍵）。說明檔 `src/AdApp/Help/`（`index.html` 與 `img/`）內嵌在程式裡，免安裝版也有；開啟時寫到 `%APPDATA%\AltiumReader2\help\<版本>\`，`{{VERSION}}` 換成目前版本。

## 介面（仿 AD19）

- **Projects 面板**（左）：每個 `.PrjPcb` 專案底下的 Source Documents **同時列出電路圖與 PCB**；沒有專案的檔案放在 Free Documents。和 AD 一樣，點一下已經開著分頁的檔案就切到那個分頁，沒開的檔案點兩下開啟。檔案可用 Ctrl / Shift 複選，右鍵「加入群組／移出群組」，或直接**拖曳**到專案、群組、Free Documents（移出）或「新群組」那一列。.PrjPcb 本身列出的檔案隨專案開啟，不能移出。自訂群組可在群組列按右鍵「重新命名…」（或選取後按 F2）改名，不能和其他群組同名。自訂群組（含名稱）與加進專案的檔案會隨工作階段記住，下次開啟時恢復。右鍵選單（2.8.1 起）每一項前面都有小圖示（開啟、分割檢視、加入／移出群組、重新命名、網路範圍、編譯資訊、關閉、複製路徑、在檔案總管中顯示），選單裡的檔名照原樣顯示底線（以前 `DB10005_CAN` 會少了 `_`）。
- **工作階段**：下次開啟程式時恢復上次開著的分頁（順序、分割檢視、各邊顯示中的分頁與作用中的分頁），不會把專案裡所有檔案都打開；其他檔案照樣列在 Projects 面板，點兩下開啟。2.7.0 起程式一啟動就在背景讀檔（和建立視窗同時進行，解析執行緒用較低優先權、留兩個核心給畫面），要開的 PCB 的場景也先在背景建好；在這台電腦上 21 個分頁的工作階段從約 2.8 秒縮短到約 1.4 秒恢復完成（第一個畫面約早 0.5 秒；這些數字是在鎖定畫面下量的，GPU 畫第一個畫面的時間在一般桌面上可能不同）。解析本身只占約 0.5 秒，所以沒有另外做快取。啟動時改用軟體繪圖、按 3D 才啟用 GPU 的做法試過：開啟會快一些，但 PCB 平移從約 60 fps 降到約 35–40 fps，所以沒有採用。2.7.2 起執行檔改為 ReadyToRun（預先編譯）且不壓縮：程式碼不必在啟動時才即時編譯、單一執行檔也不必每次解壓縮，在一般桌面上雙擊專案到畫面顯示出檔案約 0.9 秒、恢復 21 個分頁約 1.1 秒（2.7.1 是 1.16 / 1.49 秒），平移仍是 60 fps；代價是安裝後的執行檔從 74 MB 變成約 188 MB。Messages 面板會記錄「開啟完成：x.xx 秒」。2.8.1 再查了一次啟動時間花在哪裡（一般桌面、14 核心的 Core Ultra 5 225H）：大部分是 WPF／.NET 本身——執行環境啟動與 App.xaml 約 0.2 秒、第一個元件觸發的繪圖系統初始化約 0.15 秒、載入 Windows 預設佈景主題約 0.06–0.1 秒、視窗版面配置與 UI Automation 約 0.2 秒，程式自己的部分不多。2.8.1 改了三處：settings.json 改用編譯時產生的 JSON 程式碼讀寫（不再用反射，也少了約 200 個要即時編譯的方法）、預設關閉的 Navigator 第一次打開時才建立（也不再為關著的面板在每次換分頁時重建清單）、主視窗不另外解碼 app.ico 而直接用執行檔裡的圖示。結果（安裝版各 14 次的中位數）：恢復 21 個分頁時視窗早約 50 ms 建好、檔案早約 35 ms 開好、第一個畫面快約 1–2%；直接開專案幾乎沒差。試過但沒有採用：解析執行緒減到 4 條、視窗執行緒提高優先權、解析執行緒設成 EcoQoS（都在誤差內或更慢）；Dynamic PGO 關掉對啟動沒影響（它的重新編譯在啟動完成後才開始）；只把部分組件做成 composite 反而變慢。整個程式和 .NET 一起預先編譯成一個 composite ReadyToRun 映像，比一般 ReadyToRun 一般桌面約快 5%、限 4 核心時約快 6–16%，背景即時編譯的 CPU 時間少一半以上，磁碟多約 17 MB；不過 .NET 7 起的 SDK 在「單一執行檔＋ReadyToRun」發佈時預設就是 composite（`Microsoft.NET.CrossGen.targets`），所以 2.7.2 起的發行版本來就是這樣建置的（上面那些比較是用資料夾版量的，資料夾版預設不是 composite）。現在 `src/AdApp/AdApp.csproj` 明寫 `PublishReadyToRunComposite=true`，以免日後的 SDK 改了預設而沒人發現，產生的執行檔和 2.8.1 相同。另外注意：換過 ReadyToRun 設定（例如資料夾版、只做部分 composite）再發佈前，要先刪掉 `objRelease
et10.0-windowswin-x64R2R`，否則裡面留下的 composite 元件會讓程式在啟動時當掉。
- **面板配置**：每個面板的自動隱藏（圖釘）與寬度在關閉程式時記下，下次開啟恢復；自動隱藏的面板展開時和停靠時一樣寬（之後拖曳邊緣調整的寬度也會記住）。展開的面板在點到面板以外的地方（或游標移開、面板失去焦點）後立刻以約 0.375 秒的動畫收回側邊；在面板裡面點選（例如點 Projects 裡的檔案、按右鍵開選單）不會讓它收回；收回途中再點它的標籤會停住。
- **Navigator 面板**（左，另一分頁）：目前專案的元件、網路、BOM（逐顆／合併），可複製 Markdown 表格（BOM、網路表、跨圖紙網路表）。預設關閉（2.7.1 起），從 檢視 → 面板 打開；面板開關的狀態會記住。
- **文件分頁**（中）：每份 SchDoc / PcbDoc 一個分頁，電路圖分頁黃色、PCB 分頁綠色（黑字），仿 AD19 緊靠在一起（中間只有 1 像素分隔線）；目前的分頁較亮，關閉用的 ✕ 不另外佔位置，出現在分頁右端（必要時蓋住檔名的最後一兩個字）。可拖曳重排、拖到另一邊。Alt＋點選跨圖紙的網路時，網路延伸到的其他圖紙分頁會加藍框。
- **分割檢視**（F12 或工具列「分割檢視」）：左邊顯示同群組的電路圖、右邊顯示 PCB。預設關閉；要開專案就自動分割，可在 檔案 → 設定 打開。
- **Properties 面板**（右，電路圖用）：選取的零件／網路／框選的零件；沒選取時顯示文件摘要。標題為藍色，預設 24 pt、內容 16 pt（檔案 → 設定可改）；欄位名稱用淺灰藍、數值用白色粗體，逐列隔行底色，分段標題藍色加底線。在電路圖上雙擊零件會自動叫出 Properties，畫面停在電路圖（2.8.1 起不會因為雙擊的第一下而跳到 PCB：開著「Cross Probe 跳轉」的單一檢視裡，點一下零件要等過 Windows 的雙擊時間才切到 PCB 分頁，期間再點一下就算雙擊）；面板設成自動隱藏時，雙擊後會展開並停住，之後點別的零件 Properties 就改顯示那顆，取消選取（點空白處、Esc、改點網路、換到別的電路圖）才恢復自動隱藏。單獨看 PCB 時這個面板自動讓開，PCB 的資訊改在板子右上角的小卡顯示。
- **PCB 2D**：上方 Active Bar（選取、量測、**指示**（2.9.2，見下方）、**篩選**、顯示 帶藍色圖示；2D/3D、全圖、翻面、鏡射、旋轉、單層、NET 名稱、清除點亮；「顯示…」是圖層、顏色、NET 名稱與 **pin 腳編號**（預設關閉；開啟後焊墊上以淡黃色標出編號，和 NET 名稱同時開時長焊墊顯示「編號 NET」、方形焊墊上下兩行）等設定），右上角資訊小卡（量測、點亮中、所選物件，可收合），下方 **LS 圖層組合選單**＋彩色圖層分頁。
  - 繪圖：各層一次畫成圖磚（整塊板子的淺層縮放級別開檔就畫好），平移、縮放只是移動已畫好的圖磚；放大到更深的級別時第一次會畫一下，之後就留著。
  - 點選：以畫面上看得到的為準——游標正下方最上層的焊墊／導線優先，其次是 5 像素內最近的，再來是文字、元件本體，最後才是鋪銅；被上層鋪銅蓋住的東西點不到（穿孔焊墊、導通孔除外）。Shift＋點選加入／移出所選，拖曳框選（左→右完全在框內、右→左碰到就選；Shift 加選、Ctrl 減選）。
  - 篩選：可選元件、焊墊、導通孔、導線、圓弧、鋪銅、區域、填充、文字、禁布，Alt＋點項目只選該類；點選與框選都依照篩選。
  - 量測：吸附焊墊／導通孔中心與導線端點（停在焊墊中心時游標變成圓圈十字），Shift 鎖定 0°/45°/90°，Ctrl 吸附銅箔邊緣，Ctrl＋Shift 在鎖定方向上吸附邊緣。2.7.3 修正量測時的卡頓：以前游標每動一下，右上角資訊小卡就整張重建（選了腳數多的元件時有上百個按鈕與文字框），板子也整張重畫（點亮大片鋪銅或開了 pin 腳編號時一次約 25–65 ms）；在 Urukul（4.3 萬條導線）上量測時每次移動要 40–110 ms，偶爾到 600 ms。現在小卡只就地更新量測數字（量測時的行數固定，小卡高度不會跟著吸附變動），板子用量測工具開著時保留上一張畫面，只重畫量測線（約 1.6 ms），吸附點沒變時完全不重畫；Ctrl 吸附邊緣時跳過離游標太遠的鋪銅邊。終點跟著游標時「終點吸附」一直顯示（沒吸附是 —），Shift 鎖定顯示在「角度」那一行；按下第二點後數值仍可選取複製。保留的畫面只在量測工具開著時存在（一個畫面大小，1440×900 約 5 MB）。測試：自動化指令 `measfps`（游標每個畫面繞圈移動，回報每次移動的吸附、版面與繪圖時間）。

- **搜尋**：Ctrl＋F 開搜尋視窗（不必移到右上角），或用工具列右側的搜尋框。分類（全部／零件／NET）× 範圍（這個頁面／這個群組／全部檔案）；在電路圖上只搜電路圖、在 PCB 上只搜 PCB。結果依檔案分組、再分零件／網路，沒有結果的自動摺疊，點一下就跳過去。
- **工具列**（上方，藍色圖示）：分割檢視、Cross Probe 跳轉、適合視窗、清除點亮、匯出 PDF；右側是搜尋。
- **檔案 → 設定**：面板字體、Properties 字體、電路圖文字大小（50–250%，和 檢視 → 電路圖字體大小 同一個設定）、PCB 長度單位（mm / mil）、PCB 量測文字的大小與顏色（8 種預設色或自訂 #RRGGBB，附即時預覽）、Alt＋點選 NET 的雙向查詢（PCB → 電路圖為實驗功能）、Cross Probe 跳轉、從電路圖點選元件時同時點亮 PCB 上的元件（預設關閉；反方向不會讓電路圖「只看」）、自動分割、電路圖是否顯示元件值與參數。
- **Messages 面板**（下方自動隱藏）：載入、編譯、錯誤訊息。預設關閉（2.7.1 起），從 檢視 → 面板 打開；有檔案開不了時會自動出現。狀態列顯示座標與 Cross Probe 結果，最右下角是 **mm / mil 切換**（也可按 Q，或在設定中改）。

## STEP 3D 模型（2.9.0 起）

2.8 以前 3D 檢視把 STEP 本體畫成「Altium 記錄的外框，從離板高度擠出到總高度」，所以直立的壓敏電阻變成一塊平躺的板、電感與共模電感變成方塊。2.9.0 起直接讀 PcbDoc 內嵌的 STEP 模型（`Models/Data` 列出模型、`Models/<n>` 是 zlib 壓縮的 STEP 文字），照實際外形與顏色顯示：

- `src/AdCore/Step/`：自己寫的 STEP（ISO 10303-21）讀取與三角化，沒有加入新的函式庫（OpenCascade 之類的幾何核心要多數十 MB）。
  - `StepFile.cs`：記錄索引（用到才解析）、長度／角度單位、座標系。
  - `StepShapes.cs`：實體與殼、組合件（`NEXT_ASSEMBLY_USAGE_OCCURRENCE` 判斷父子，SolidWorks 匯出的方向和標準相反也能處理）、`MAPPED_ITEM`、面與實體的顏色（`STYLED_ITEM`）。
  - `StepTess.cs`：平面、圓柱、圓錐、球、環面、B-spline（含有理）曲面與線性拉伸面；直線、圓、橢圓、B-spline 曲線與折線。每條邊只取樣一次（兩個面共用，不會有裂縫），每個面在自己的參數空間三角化，曲面再沿格線切開以貼合曲率；跨接縫的環、極點、圓錐頂點都有處理。
  - `Earcut.cs`：多邊形（含孔）三角化，移植自 Mapbox earcut（ISC，授權見 THIRD-PARTY-NOTICES）。
  - `StepModel.cs`：整個模型 → 依顏色分組的三角形；讀 PcbDoc 內嵌的模型（背景執行，最多 4 條執行緒）。
- 擺放方式（`Pcb3DView.StepPlacement`）：模型先繞自身 X、再 Y、再 Z 轉 `MODEL.3D.ROTX/Y/Z`，再加 `MODEL.2D.ROTATION`，原點放在 `MODEL.2D.X/Y`，頂面往上 `MODEL.3D.DZ`；底面元件繞 X 翻 180°（等於以原點為中心鏡射 Y），從底面往下 `DZ`。用兩塊測試板全部 1175 個 STEP 本體比對 Altium 存的外框與高度：1168 個完全吻合，其餘 7 個是轉 45° 的元件（Altium 的外框是模型原始方向的矩形轉過去，比實際外形大，畫面上位置正確）。
- 密度：弦高誤差 0.03 mm、每段最多 20°（半徑很小的倒角放寬到 45°–90°）、邊線再以 Douglas-Peucker 精簡；B-spline 面最多約 100 格但每格不超過 1/4 圈；單一模型超過 8000 個三角形就用較粗的參數（0.075 mm、35°）再做一次。
- 讀取期間先以外框顯示，讀完自動換成模型；同一個模型的三角形只做一次，所有用到它的元件共用。讀不出來的模型、沒有內嵌（只連結外部檔案）的模型、Parasolid 模型，仍以外框擠出顯示。3D「顯示」選單可關閉「使用元件的 STEP 3D 模型」，回到外框顯示。
- 量測（Debug 版，同一個程式比較 STEP 開／關；一般桌面）：
  | 板子 | 模型 | 面 | 失敗 | 三角形（不重複） | 讀取 | 3D 檢視的記憶體 |
  |---|---|---|---|---|---|---|
  | Urukul（1050 個元件） | 58 | 10,805 | 4 | 約 10.8 萬 | 1.4 秒 | 741 → 823 MB（+82 MB） |
  | DieBieMS BMS（275 個元件） | 29 | 5,285 | 0 | 約 4.8 萬 | 0.6 秒 | 628 → 711 MB（+83 MB） |
  失敗的面是比 0.03 mm 還薄的細縫或 Altium 自己也空著的面，畫面上看不出來。只有切到 3D 時才會讀模型，啟動時間、2D 檢視與安裝大小不受影響。
- 開發時另外用 Node.js 寫了同樣演算法的原型，在瀏覽器裡逐一看過兩塊測試板上的元件（TO-263、SMA 連接器、變壓器的繞線、晶片電容等）再移植成 C#。

## 2.9.4：指示標記預設 75%、拿掉擴散白圈

- 手指標記與游標的預設大小改為 75%（約 35 DIP 高，原本 46）。2.9.2–2.9.3 會把當時的預設 100% 寫進 settings.json，所以第一次用 2.9.4 開啟時，設定裡剛好是 100% 的會改成 75%（只做一次，設定版本 3）；調成其他大小的保持不變。
- 拿掉每個標記從指尖向外擴散的白圈動畫（`PcbView.Finger.cs` 不再在畫布上疊 WPF 動畫）；標記本身的洋紅色、深色底、白色光暈與指尖青點不變，都是靜態的。

## 2.9.3：拿掉「按住空白鍵拖曳平移」

電路圖與 PCB 2D 都不再用「按住空白鍵＋左鍵拖曳」平移，避免誤用（例如在「指示」工具裡空白鍵是轉向）。平移改用右鍵或中鍵拖曳（「指示」工具裡左鍵拖曳也可以），滾輪縮放不變。

## 2.9.2：指示標記（point finger）、Parasolid 二進位模型

- **指示標記（Active Bar「指示」或 <kbd>P</kbd>）**：給功能師找到零件後把多個位置指出來，再看著整片 PCB 去重工或修改。
  - 游標變成一隻手指（`Views/FingerArt.cs` 畫手、`Views/PcbView.Finger.cs` 處理操作）；預設朝左上（-45°），每次開啟都從 -45° 開始，<kbd>空白鍵</kbd>以指尖為圓心順時針轉 45°（工具開著時左鍵拖曳也能平移；右鍵／中鍵拖曳照常平移）。
  - 左鍵在板上留下同方向的手指：記住的是指尖在板上的座標與板上的方向，所以平移、縮放、旋轉、鏡射、翻面後都還指著同一點、同一方向，而且在螢幕上永遠和游標一樣大。<kbd>Ctrl</kbd>＋左鍵拿掉最近的一個，<kbd>Esc</kbd> 清除全部（沒有標記時離開工具），右鍵選單也有「清除指示標記」。
  - 全圖時的可視性：一開始用黃色的手，在 Urukul 這種紅黃為主的板子上會和銅箔混在一起，所以改成霓虹洋紅（銅箔層不會用的顏色）＋深色外框、白色光暈、指尖青色圓點，標記在板上還加一圈柔和的深色底；另外每個標記有一圈從指尖向外擴散的白圈（WPF 動畫，疊在畫布上，不必每一格重畫整塊板子；不同標記錯開時間，不會整片同時閃；2.9.4 拿掉）。
  - 左下角面板：大小 10–300%（同時改游標與標記，位置與方向不變，記在設定裡；2.9.4 起預設 75%）、已標記數量、清除全部。
  - 游標是程式產生的 .cur（手的圖、熱點在指尖，依螢幕 DPI 放大，最大 256 px）。
- **Parasolid 二進位檔（.x_b）**：Altium 嵌入的 .x_b 是 neutral binary（大端序、指標以 index＋1 的 2 位元組表示），而且帶有和基準 schema（SCH_13006）的差異表（每種節點第一次出現時寫出 Copy／Delete／Insert／Append 指令）。讀取器照這個差異表組出每種節點的欄位，和 .x_t 共用同一套節點與三角化。使用者那塊板子上的 PTC（PTCE5／PTCE6）因此也照實際外形顯示：10 個面全部成功。基準 schema 和參考文件不同的地方（EDGE 多一個欄位、ATTRIB_DEF 的陣列長度、LIST 的欄位）由這個檔案的差異表核對過。

## 2.9.1：Altium 的圓柱本體旋轉、Parasolid 模型

使用者提供的板子（AD19 畫面為準）在 2.9.0 仍有兩個問題，原因都不是 STEP：

- **壓敏電阻倒下**：這顆元件是 Altium 自己的「圓柱」本體（`MODEL.MODELTYPE=2`）組成的，圓盤那一段 `MODEL.3D.ROTX=90`。舊版把圓柱一律畫成直立、從離板高度往上，忽略了旋轉，所以立著的圓盤變成平躺。現在圓柱以「底面圓心在模型原點、軸朝 +z」建立，再和 STEP 模型同樣依 X→Y→Z 旋轉、`MODEL.2D.X/Y` 與 `MODEL.3D.DZ` 擺放（底面元件繞 X 翻面）；球體以 `DZ` 為球心。三塊板子 207 個圓柱／球體本體比對 Altium 存的外框與高度：200 個吻合，7 個大圓盤差 0.05–0.09 mm（Altium 的外框是多邊形近似的圓）。
- **共模電感變成方塊**：它的模型是 Parasolid 文字檔（SolidWorks 2022 匯出的 `.x_t`，嵌在 PcbDoc 裡），不是 STEP，2.9.0 只讀 STEP，所以退回外框擠出。現在 `src/AdCore/Step/XtFile.cs` 依公開的《Parasolid XT Format Reference》（2006／2008）讀 XT 文字格式的節點，`XtModel.cs` 把實體、面、loop／fin、邊與曲面轉給同一個三角化程式：平面、圓柱、圓錐、球、環面、B 曲面、偏移與掃掠曲面；直線、圓、橢圓、B 曲線、修剪曲線、SP 曲線（曲面參數空間裡的 2D 曲線）、相交曲線；顏色取自面與實體的 `SDL/TYSA_COLOUR` 屬性；單位公尺換成 mm。參考文件是舊版 schema，schema 28（Parasolid 33）有幾個節點多了或調換了欄位（BODY、EDGE、REGION、LIST、POINTER_LIS_BLOCK、ATTRIB_DEF、TRANSFORM），程式先用新的欄位配置讀、失敗再用文件的配置。
- 這顆共模電感：130 個面全部成功、7319 個三角形、讀取 0.2 秒以內；整塊板子的 3D 畫面（壓敏電阻、共模電感、保險絲、Y 電容）和 AD19 的畫面一致。
- 2.9.2 起 Parasolid 二進位檔（`.x_b`）與帶有自己 schema 差異表的 XT 檔也能讀（見上方 2.9.2）；Parasolid 的倒角（blend）、旋轉曲面目前以邊界平面填補。
- 3D「顯示」選單的「使用元件的 STEP 3D 模型」開關同樣控制 Parasolid 模型。

## 三項核心需求

1. **吃 .SchDoc / .PcbDoc / 專案檔**：開檔對話框、開資料夾、拖放、命令列、雙擊（開啟方式）都可以。雙擊單一 SchDoc/PcbDoc 時，若同資料夾有列出它的 .PrjPcb，會整個專案一起開。
2. **同專案／群組雙向查詢跳轉**：電路圖點元件（或左鍵拖曳框選多個）→ PCB 選取並放大；PCB 點元件（或它的焊墊）→ 電路圖切到含該元件的圖紙並放大。多個專案同時開啟時依 .PrjPcb 判斷對應的板子。「Cross Probe 跳轉」關閉時，另一邊只在背景更新選取／點亮：不切換分頁（分割檢視也一樣）、不換圖紙、不縮放。
3. **Alt + 點選 net → 同群組 PCB 點亮同一個 net**：以接腳（位號＋腳號）比對、名稱為輔，自動命名或經 Port 改名的網路也找得到；同專案其他圖紙一起標示，Projects 面板在含該網路的文件旁標「可跳轉」。網路在多個頁面上時，電路圖上方的網路標示列與 Properties 的「頁面」會列出**所有**頁面（含目前這一頁，多頁的檔案逐頁列出），目前的頁面以藍底深色粗體反白標示（Projects 面板的目前檔案也一樣）；點其他頁面就切過去並標示同一個網路（沒開著的分頁會自動開啟），點目前頁面則縮放到這個網路。PCB 上 Alt＋點選 NET 也會反向標到電路圖（實驗功能，可在設定中關閉）；Ctrl＋點選只點亮、不查詢。

## 測試

`tools/AdTest` 會啟動程式（`--automation-port`），用 Windows 真實滑鼠事件點電路圖元件、Alt+點選網路、點 PCB 元件，並檢查兩邊的選取與點亮結果、截圖。已用 DieBieMS（10 張電路圖）與 Urukul（階層式、3 塊 PcbDoc、4.3 萬條導線）兩個在 GitHub 上公開的 Altium 專案、KiCad 8 與 Eagle 7.7 檔案測過。
測試用的啟動參數：`--automation-port N --automation-token T`（開自動化連接埠，T 至少 16 字元，每個要求都要帶 `X-Automation-Token: T` 標頭；AdTest 每次自動產生隨機的 T；預設不恢復上次的檔案）、`--restore`（照樣恢復上次的工作階段）、`--settings <資料夾>`（設定檔改放這裡，不動到真正的設定）。
